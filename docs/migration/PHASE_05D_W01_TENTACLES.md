# Fase 5D · Lote de 20 tentáculos W-01

Se exportó `w01_tentacles.glb` desde los 20 anclajes de `Tentacles.ts`: diez miembros frontales/laterales y diez dorsales. El lote contiene las curvas base, tubos de 28×9 segmentos, reducción radial, 87 ventosas y 87 centros orgánicos.

- 20 tentáculos.
- 87 conjuntos de ventosa.
- 194 instancias visibles.
- 302 nodos.
- Textura de piel embebida.
- SHA-256: `e950ad693601988bb4e4b68c673089a019ba67fac6544102e395863ead984207`.
- Dos exportaciones idénticas byte a byte.

La geometría representa la pose base fuente. La locomoción, extensión, ataque, apoyo, colisión con facetas, pulsación y orientación dinámica de ventosas se calculan cada frame en el original y deben implementarse como rig nativo; no se declaran completadas por este GLB.
